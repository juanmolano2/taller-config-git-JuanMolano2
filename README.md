# Taller de configuración y Git

Nombre: Juan Molano
Grupo: solo yo

## Lo que aprendí

- Las variables de entorno permiten cambiar la configuración sin cambiar el código.
- .gitignore evita que Git rastree archivos locales como .env.
- git rm --cached deja de rastrear un archivo sin borrarlo de mi carpeta.
- Las ramas feature y los Pull Requests permiten revisar cambios antes de integrarlos.
